# 잇플 인사이트 자동화 운영 안내

Europe PMC에서 최근 30일의 식품·영양 논문을 수집하고 DOI·원문·CC0/CC BY 조건과 Crossref 정정·철회 정보를 확인합니다. 소재 선정, 원문 분석, 1,500~2,500자 한국어 작성, 독립 검증은 모두 `gpt-6-luna`를 사용합니다. 원문에 없는 인용, 근거보다 강한 건강 주장, 임의 복용량을 차단합니다. 정정·철회 조회는 제공처에 등록된 정보 범위의 확인입니다.

대표 이미지는 `gpt-image-2`로 1536×1024 중간 품질로 생성한 뒤 WebP 1200×800으로 저장합니다. 음식과 식생활을 표현하는 설명용 이미지이며 연구 수치·치료 효과를 그림으로 만들지 않습니다. 실패하면 게시를 보류하고 재시도하거나 직접 업로드합니다. 기존 글처럼 대표 이미지와 본문 이미지 배치를 지원합니다. 본문 이미지는 최대 3개이며 대체 텍스트, 설명·출처, 배치 위치를 입력합니다. 직접 올리는 이미지는 사용 권한을 확인해주세요.

쿠팡 로그인·자동 링크 생성 실행기는 제외했습니다. 검수 화면에서 상품명과 쿠팡 제휴 링크를 직접 입력합니다. 원본 상품 URL은 선택 사항이고 배송 유형은 실제 확인한 값을 선택합니다. 로켓배송 상품을 우선 선택해주세요. 상품은 최대 3개이며 상품 없이 게시할 수도 있습니다. 재검증 후에도 직접 입력한 링크와 이미지를 보존합니다. 공개 화면은 제휴 고지와 `rel="sponsored"`를 표시합니다.

## 설치와 예약 실행

1. 실제 잇플 Supabase 프로젝트 `ovncracjrivndsjjfyoe`에 `migrations/016_insight_automation.sql`을 적용합니다. 기존 영양 게시물 테이블이 필요하며 재적용할 수 있습니다.
2. Node.js 22 이상에서 `npm ci`를 실행합니다. 서버 환경변수는 `SUPABASE_URL`, `SUPABASE_KEY`, `SUPABASE_SERVICE_ROLE_KEY`, `OPENAI_API_KEY`, 기존 세션·로그인 설정입니다.
3. Render의 My Workspace에서 `render-insight.yaml`을 별도 Blueprint로 연결합니다. 기존 `eatple` 웹 서버의 DB/OpenAI 환경변수를 Render 내부에서 참조합니다. 기존 웹 서버를 다시 생성하지 않습니다.
4. 관리자 **인사이트 자동화** 탭에서 예약 실행을 활성화합니다. UTC 매 30분 실행되지만 한국시간 오전 7시 이후 하루 최대 1편을 생성합니다. 미완료 작업이 7편이면 수집을 멈춥니다. 수동 수집·처리도 지원합니다.

기본 월 AI 예산 상한은 60,000원이며 이미지 비용도 같은 상한에 포함합니다. 호출 전에 비용을 예약하고 타임아웃 비용도 반영합니다. Luna 기본 추정 단가는 입력 150원·출력 750원/100만 토큰, 환율 1,500원 가정입니다. 이미지 호출당 200원을 보수적으로 예약하고 사용량이 있으면 GPT Image 2 단가로 추정합니다. 실제 청구·환율·세금은 공급자 내역과 비교해주세요. Render Cron은 월 최소 $1와 실행 시간에 따른 비용이며 월 2만원 고정 결제를 설정하지 않았습니다.

## SEO와 검수

제목·요약·본문은 중학생도 이해할 수 있는 표현으로 작성합니다. 문장은 짧게 쓰고 꼭 필요한 전문 용어는 바로 쉬운 말로 풉니다. 불필요한 영어 약어·통계 기호와 숫자 나열은 줄입니다. 결과를 설명할 때마다 같은 주의 문구를 붙이지 않고, **연구의 한계점** 섹션 하나에 연구 기간·근거의 확실성·다른 사람에게 적용할 때의 제한을 모읍니다. 동물 실험인지, 질병 회복이 아니라 검사 수치를 측정했는지처럼 결과를 오해하지 않으려면 꼭 필요한 조건은 결과 설명에도 남깁니다. 검증은 글 전체를 읽고 판단하며 한계 문구를 문단마다 요구하지 않습니다. 원문 인용과 내부 분석 자료는 정확성을 위해 전문 표현을 보존합니다.

검색 의도에 맞는 주제 키워드를 제목·요약·첫 문단·소제목에 자연스럽게 배치합니다. 반복 키워드, 과장 제목, 없는 경험·효능을 추가하지 않습니다. 관리자 화면에 키워드 배치, 제목·설명 길이, 소제목, 출처, 이미지 대체 텍스트의 내부 점수와 보완 항목을 표시합니다. **이 점수는 구글의 점수나 검색 순위 예측이 아닙니다.**

공개 페이지는 JavaScript 실행 전에도 H1·H2 본문과 안전한 이미지를 제공합니다. 게시물별 title, description, canonical, OG 이미지, Article 구조화 데이터, 출처 링크를 생성합니다. 사이트맵은 공개 게시물의 canonical 상세 URL을 포함합니다. 정확한 근거·한계·편집 주체·AI 이용 방식이 드러나도록 작성합니다.

원문 근거, 연구 대상·결과·한계, 이미지, 상품 링크, 미리보기를 검수하세요. 수정 저장은 기존 검증을 무효화하고 재검증 대기로 되돌립니다. **대기 글 생성·검증** 또는 Cron이 재검증합니다. 대표 이미지 준비, 내부 SEO 80점 이상, 현재 버전의 근거 검증 통과 후 **현재 버전 승인·게시**로 공개합니다. 승인 직전 정정·철회 상태를 다시 확인합니다. 자동 작업은 운영자 승인 없이 글을 공개하지 않습니다.

내부 작업·근거·비용은 RLS로 보호합니다. 초안과 그 상품·태그도 공개 조회할 수 없습니다. 기존 일괄 게시·편집 기능으로 검증을 건너뛰지 못하도록 DB 트리거를 적용합니다.

## 확인

`npm test`와 `npm run check`를 실행합니다. PostgreSQL 엔진(PGlite)으로 마이그레이션 재적용, RLS, 임대·중복 방지, 버전, 링크·이미지 보존, 게시 트랜잭션, 예산 상한을 검증합니다. SEO 점검과 서버 HTML의 메타데이터·이미지·스크립트 제거도 검사합니다. 외부 API 가용성과 실제 검색 순위는 자동 테스트가 보장하지 않습니다.
