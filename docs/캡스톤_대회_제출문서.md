## 1. 과제의 개요

### 1.1 과제 배경 및 필요성

현대인들은 건강한 식생활에 대한 관심이 높아지고 있으나, 개인의 건강 상태, 알레르기, 식습관 등을 종합적으로 고려한 맞춤형 식단 구성은 전문가의 도움이 없이는 어려운 실정입니다. 또한 시중에 판매되는 수많은 영양제 중에서 자신에게 적합한 제품을 선택하는 것도 복잡한 과정입니다.

더욱이 인터넷상에는 불분명한 출처의 건강 정보와 영양 정보가 범람하고 있어, 사용자 개인에게 필요하고 정확한 영양정보를 얻기 어려운 상황입니다. 이러한 문제를 해결하기 위해 **논문 기반의 신뢰할 수 있는 영양정보 서비스(잇플인사이트)**를 개발하여, 과학적으로 검증된 연구 논문을 바탕으로 정확하고 신뢰성 있는 영양 정보를 제공하고자 합니다.

이러한 문제점들을 종합적으로 해결하기 위해 **AI 기술을 활용한 통합 건강 관리 플랫폼**이 필요하며, 사용자의 개인 정보를 기반으로 식단, 영양제, 식당까지 한 번에 추천받을 수 있는 서비스의 개발이 요구됩니다.

### 1.2 과제 목표

1. **개인 맞춤형 AI 식단 추천 시스템 구축**
   - 사용자의 건강 목표, 알레르기, 식습관을 고려한 맞춤 식단 생성
   - 영양 정보 및 조리법 제공

2. **신뢰성 있는 영양제 추천 시스템 개발**
   - 식약처 승인 건강기능식품 42,000개 데이터베이스 구축
   - 알레르기 및 약물 상호작용 고려한 안전한 추천

3. **논문 기반 영양정보 서비스(잇플인사이트) 구축**
   - PubMed를 활용한 과학적으로 검증된 연구 논문 기반 영양정보 제공
   - 불분명한 출처의 정보 대신 신뢰할 수 있는 영양정보 제공
   - AI 기반 논문 분석, 요약 및 한국어 번역 서비스

4. **위치 기반 식당 추천 서비스 제공**
   - 사용자 건강 정보를 고려한 주변 식당 추천
   - 실시간 정보 검색 및 분석

5. **사용자 참여 및 재미 요소 추가**
   - 미니게임을 통한 포인트 적립 시스템
   - 주간 리더보드 및 보상 시스템

## 2. 작품소개

### 2.1 작품명
**잇플 (ItPlan)** - AI 기반 건강 관리 플랫폼

### 2.2 작품 개요

잇플은 **Google Gemini AI**를 활용하여 사용자의 개인 건강 정보를 분석하고, 맞춤형 식단, 영양제, 식당을 추천하는 통합 건강 관리 플랫폼입니다. 특히 **논문 기반 영양정보 서비스(잇플인사이트)**를 통해 불분명한 출처의 정보 대신 과학적으로 검증된 연구 논문을 바탕으로 한 신뢰할 수 있는 영양정보를 제공합니다. 단순한 정보 제공을 넘어서 실제 사용 가능한 실용적인 추천 서비스를 제공하며, 사용자의 건강한 라이프스타일 형성을 돕습니다.

### 2.3 핵심 차별화 포인트

1. **논문 기반 신뢰성 있는 영양정보 제공**
   - PubMed를 활용한 과학적으로 검증된 연구 논문 기반 정보 제공
   - 불분명한 출처의 정보 범람 문제 해결
   - AI 기반 논문 분석 및 한국어 번역으로 접근성 향상

2. **실제 검증된 데이터 기반 서비스**
   - AI 추천 결과의 실제 조리 가능성 및 가격대 검증
   - 식약처 승인 건강기능식품만 검색 가능한 안전한 추천

3. **대용량 데이터 처리 최적화**
   - 42,000개 건강기능식품 데이터베이스 병렬 처리
   - 스마트 캐싱 시스템으로 응답 속도 최대 10배 향상

4. **통합 건강 관리 솔루션**
   - 식단, 영양제, 식당 추천을 하나의 플랫폼에서 제공
   - 사용자 프로필 기반 일관된 추천 경험

5. **사용자 참여 유도 시스템**
   - 게임을 통한 포인트 적립 및 리더보드 시스템
   - 건강 정보 학습을 통한 지속적인 사용 동기 부여

### 2.4 주요 기능 요약

| 기능 | 설명 |

| AI 영양제 추천 | 식약처 승인 제품만 검색, 알레르기 및 약물 상호작용 고려 |

## 3. 작품내용 및 상세구현

### 3.1 시스템 아키텍처

#### 3.1.1 기술 스택

**백엔드**
- **Node.js** + **Express.js**: 서버 런타임 및 웹 프레임워크
- **PostgreSQL**: 사용자 데이터 및 영양 정보 데이터베이스
- **Supabase**: 클라우드 데이터베이스 및 인증 서비스
- **Axios**: HTTP 클라이언트 및 외부 API 연동

**프론트엔드**
- **HTML5/CSS3**: 반응형 웹 디자인
- **JavaScript (ES6+)**: 클라이언트 사이드 로직
- **카카오 지도 API**: 위치 기반 서비스

**AI 및 외부 서비스**
- **Google Gemini API**: AI 추천 시스템 (Gemini 2.5 Pro)
- **Google Search API**: 실시간 정보 검색
- **식약처 건강기능식품 API**: 42,000개 제품 데이터
- **PubMed API**: 과학적으로 검증된 연구 논문 수집 (잇플인사이트)
- **카카오 REST API**: 식당 검색
- **News API**: 건강 관련 뉴스 수집
- **YouTube Data API**: 영양/건강 영상 검색

### 3.2 주요 기능 상세 구현

#### 3.2.1 AI 맞춤 식단 구성 시스템

**구현 내용**
- 사용자 프로필 정보(나이, 키, 체중, 성별, 건강 목표, 알레르기 등)를 입력받아 Google Gemini 2.5 Pro 모델에 전달
- AI가 개인화된 식단을 생성하고, 각 메뉴별 영양 정보, 조리법, 예상 비용 제공
- 캐시 시스템을 통한 동일 요청 시 빠른 응답 제공

**기술적 특징**
- SHA-256 해시 기반 캐시 키 생성으로 정확한 캐시 매칭
- 300초 타임아웃 설정으로 안정적인 응답 보장
- 사용자별 서비스 이용 횟수 추적

**검증 프로세스**
- 실제 식재료 구매를 통한 AI 추천 식단의 조리 가능성 검증
- 영양 정보 정확도 검증 및 데이터베이스 보강
- 가격대 실현가능성 검증

#### 3.2.2 AI 영양제 추천 시스템

**구현 내용**
- 식약처 승인 건강기능식품 42,000개 데이터베이스 구축
- 사용자 건강 상태, 알레르기, 복용 중인 약물 정보를 분석하여 적합한 영양제 추천
- 우선순위별 영양제 목록 제공 및 상호작용 경고

**성능 최적화**
- **병렬 처리**: 순차적 API 호출을 5개 동시 요청으로 변경하여 속도 5-8배 향상
  - 기존: 42,000개 제품 로드 시 ~120-180초
  - 개선: 첫 로드 ~25-40초, 캐시 사용 시 ~0.1-0.5초
- **스마트 캐싱**: 24시간 캐시 시스템으로 응답시간 최대 10배 단축
- **배치 최적화**: 1000개씩 배치 처리로 API 부하 분산
- **자동 복구**: 실패한 배치 자동 재시도 및 부분 성공 처리

**지능형 검색 기능**
- 유사도 기반 영양제 명칭 매칭
  - "크롬 피콜리네이트" → "크롬피콜리네이트" 자동 매칭
  - "아슈와간다" → "KSM-66", "위타니아" 등 별명 매칭
  - "CoQ10" → "코큐텐", "코엔자임Q10" 등 다양한 표기 지원

**데이터 검증**
- 실제 건강기능식품 샘플 구매를 통한 식약처 인증 정보 일치도 검증
- AI 추천 영양제의 실제 구매 가능 여부 확인
- 가격대 및 효과성 정보 정확도 검증

#### 3.2.3 AI 식당 추천 시스템

**구현 내용**
- 카카오 지도 API를 활용한 위치 기반 주변 식당 검색 (1km 반경)
- Google Search API를 활용한 실시간 식당 정보 검색
- 사용자 건강 정보(알레르기, 식이 제한 등)를 고려한 AI 추천

**추천 프로세스**
1. 사용자 위치 설정 (카카오 지도)
2. 사용자 프로필 입력 (신체 정보, 건강 정보, 생활 패턴)
3. 식당 조건 설정 (음식 카테고리, 가격대, 영업시간)
4. 주변 식당 검색 및 AI 분석을 통한 맞춤 추천

#### 3.2.4 식재료 성분 분석 시스템

**구현 내용**
- AI 기반 식재료 영양성분 분석
- 알레르기 유발 성분 분석
- 식재료별 건강 효능 정보 제공

**검증 프로세스**
- 실제 식재료 구매를 통한 AI 분석 결과 정확도 검증
- 영양 정보 데이터베이스 보강 및 업데이트

#### 3.2.5 미니게임 및 포인트 시스템

**구현 내용**
- **스네이크 게임**: 클래식 스네이크 게임을 통한 포인트 적립
- **기억력 게임**: 카드 매칭 게임을 통한 포인트 적립
- **퍼즐 게임**: 퍼즐 해결을 통한 포인트 적립

**포인트 시스템**
- 게임 플레이를 통한 일일 포인트 획득
- 일일 포인트 획득 한도 관리
- **주간 리더보드 시스템**: 매주 월요일 00:00 초기화
  - 1등: 500포인트
  - 2등: 300포인트
  - 3등: 200포인트

**기술적 특징**
- Node-cron을 활용한 주간 리더보드 자동 초기화
- 실시간 포인트 업데이트 및 순위 표시

#### 3.2.6 잇플인사이트: 논문 기반 영양정보 시스템

**구현 배경**
- 인터넷상의 불분명한 출처의 건강 정보 범람 문제 해결
- 사용자 개인에게 필요하고 정확한 영양정보 제공의 어려움 해소
- 과학적으로 검증된 연구 논문을 바탕으로 한 신뢰할 수 있는 영양정보 제공

**구현 내용**
- **PubMed API를 활용한 논문 검색 및 수집**: 과학적으로 검증된 연구 논문 수집
- **AI 기반 논문 분석 및 요약**: 복잡한 논문 내용을 이해하기 쉽게 요약
- **한국어 번역 서비스**: 영문 논문을 한국어로 번역하여 접근성 향상
- **신뢰도 점수 계산**: 논문의 신뢰도와 관련성을 평가하여 우선순위 결정
- **중복 콘텐츠 필터링**: 동일하거나 유사한 정보의 중복 제공 방지
- **YouTube Data API**: 영양/건강 영상 검색 및 연계 제공
- **News API**: 최신 건강 관련 뉴스 수집 및 제공
- **AI 기반 썸네일 이미지 생성**: 시각적으로 매력적인 콘텐츠 제공

**자동화 시스템**
- Node-cron을 활용한 정기적 데이터 수집 스케줄러
- 수집 오류 처리 및 재시도 로직
- 성능 모니터링 및 로깅 시스템

### 3.3 데이터베이스 설계

- **nutrition_categories**: 영양 정보 카테고리

- **reviews**: 제품 리뷰
- **promotions**: 프로모션 정보
- **points**: 사용자 포인트 정보
- **weekly_leaderboard**: 주간 리더보드

#### 3.3.2 성능 최적화

- 인덱스 최적화를 통한 검색 속도 향상
- 캐시 시스템을 통한 데이터베이스 부하 감소
- 배치 처리 및 병렬 처리로 대용량 데이터 처리

## 4. 활용방안 및 기대효과

### 4.1 활용방안

#### 4.1.1 개인 사용자

2. **영양제 선택**: 건강 검진 결과를 바탕으로 필요한 영양제 추천받기
3. **신뢰할 수 있는 영양정보 확인**: 잇플인사이트를 통해 논문 기반의 정확한 영양정보 확인
4. **외식 선택**: 주변 식당 중 건강에 좋은 메뉴를 제공하는 곳 찾기

## 5. 결론

잇플(ItPlan)은 AI 기술을 활용하여 사용자의 건강한 식생활을 돕는 통합 건강 관리 플랫폼입니다. 특히 인터넷상의 불분명한 출처의 건강 정보 범람 문제를 해결하기 위해 **논문 기반 영양정보 서비스(잇플인사이트)**를 제공하여, 과학적으로 검증된 연구 논문을 바탕으로 한 신뢰할 수 있는 영양정보를 제공합니다. 단순한 정보 제공을 넘어서 실제 사용 가능한 맞춤형 추천 서비스를 제공하며, 검증된 데이터 기반으로 신뢰성 있는 서비스를 제공합니다.

대용량 데이터 처리 최적화, 스마트 캐싱 시스템, 지능형 검색 기능 등을 통해 사용자에게 빠르고 정확한 서비스를 제공하며, 게임 시스템을 통한 사용자 참여 유도로 지속적인 사용을 장려합니다.

향후 모바일 앱 개발, 기능 확장, 비즈니스 모델 구축을 통해 더 많은 사용자에게 건강한 라이프스타일을 제공하는 서비스로 성장할 수 있을 것입니다.
